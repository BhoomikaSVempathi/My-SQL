# MySQL - Employee Performance & HR Analytics

This repository contains structured SQL projects and queries designed to analyze employee performance and support HR decision-making processes. The focus is on relational database design, complex query formulation, and optimization for real-world business insights.

## 📌 Features

- Employee performance mapping using rating inputs from managers.
- Identification of top salaries and job-role alignment to organizational standards.
- Relational database design with dataset imports and ER diagrams.
- Complex queries for performance, bonus calculation, and departmental reporting.
- Query optimization using indexing for improved execution times.
- Salary distribution analysis by continent and country to support compensation strategies.

## 🛠️ Technologies Used

- MySQL
- ER Diagram tools (e.g., dbdiagram.io or MySQL Workbench)

## 🚀 How to Run

1. Clone the repository.
2. Import the SQL dump or datasets into your MySQL server.
3. Open and run queries in MySQL Workbench or any preferred SQL IDE.
4. Review ER diagram and optimize queries as needed.

## 📈 Use Case

This project can be applied by HR departments or analysts to better understand workforce dynamics, streamline salary decisions, and evaluate performance across departments.
